Arquitectura y Funciones del Sistema Operativo

Análisis profundo de la capa de software que interrumpe la interacción directa entre el usuario y el hardware, gestionando los recursos críticos del sistema.

¿Qué es un Sistema Operativo?

Un Sistema Operativo (SO) es el programa fundamental que gestiona el hardware de la computadora y proporciona servicios comunes para los programas de aplicación. Actúa como una capa de abstracción que oculta la complejidad del hardware al programador y al usuario.

"Sin el SO, cada programa tendría que saber exactamente cómo escribir datos en el sector X del disco duro o cómo enviar un voltaje específico al pin Y de la tarjeta de red."

Elementos Funcionales

El Kernel (Núcleo)

La parte más interna del SO. Se ejecuta en modo núcleo (privilegiado) y controla el acceso al hardware. Gestiona la memoria, el tiempo de CPU y los drivers.

El Shell (Intérprete)

Capa que envuelve al núcleo. Recibe comandos del usuario, los interpreta y los traduce en System Calls (llamadas al sistema) que el Kernel puede procesar.

GUI / Interfaz

Capa visual (ventanas, iconos, menús). Es una herramienta de usabilidad que permite interactuar con el Shell y el Kernel sin necesidad de conocer la sintaxis de comandos.

Gestión de Recursos Críticos

Función de Gestión ¿Qué hace exactamente el SO? Concepto Clave
Gestión de Procesos Decide qué programa usa la CPU en cada momento y por cuánto tiempo. Maneja el cambio de contexto. Planificación (Scheduler)
Gestión de Memoria Asigna espacios de RAM a cada proceso y evita que un programa escriba en el espacio de otro. Memoria Virtual / Paginación
Gestión de E/S Administra el flujo de datos entre el sistema y los periféricos (teclado, ratón, discos) mediante drivers. Interrupciones / Buffers
Gestión de Archivos Organiza la información en el almacenamiento físico mediante estructuras lógicas (directorios, extensiones). Sistema de Archivos (FS)

Evolución Histórica y Paradigmática

Sistemas Monotarea

Un solo proceso en ejecución. El CPU espera a que el proceso termine antes de iniciar otro. (Ej: MS-DOS temprano).

Sistemas Multitarea

Capacidad de ejecutar múltiples procesos "aparentemente" a la vez mediante el reparto del tiempo del CPU.

Sistemas Multiusuario

Permiten que varios usuarios accedan a los recursos del sistema simultáneamente, gestionando permisos y cuotas.

Dato Técnico: Sistemas Distribuidos

Son aquellos que gestionan un grupo de computadoras independientes y las hacen parecer como una sola unidad para el usuario. El SO se encarga de la comunicación entre nodos y el balanceo de carga. Es la base de la infraestructura actual de la Nube (Cloud Computing).
