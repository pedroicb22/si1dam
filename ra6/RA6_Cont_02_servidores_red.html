💾 Almacenamiento: NAS vs SAN

Según la forma en que el servidor expone los datos al cliente, hablamos de almacenamiento a nivel de archivos o a nivel de bloques.

NAS (Network Attached Storage)

Un servidor de archivos dedicado. El cliente accede a través de protocolos de red (SMB, NFS).

  • • Se ve como una "unidad de red" o carpeta compartida.
  • • Ideal para backups y archivos compartidos de oficina.

SAN (Storage Area Network)

Una red de alta velocidad dedicada exclusivamente al almacenamiento de bloques (iSCSI, Fibre Channel).

  • • El sistema operativo lo ve como un disco local (LUN).
  • • Crítico para bases de datos y virtualización (VMware, Hyper-V).

🖨️ Servidores de Impresión

Centralizan la gestión de los trabajos de impresión, permitiendo controlar colas, prioridades y permisos de uso.

CUPS (Common Unix Printing System)

El estándar en Linux/macOS. Utiliza el protocolo IPP para gestionar la comunicación con la impresora.

Print Server (Windows)

Integrado en el rol de servidor de Windows, permitiendo la gestión de colas global mediante GPOs.

💻 Acceso Remoto y Consola

Acceso CLI (Línea de Comandos)

El estándar es SSH (Secure Shell). Cifra todo el tráfico, eliminando la vulnerabilidad de Telnet.

Acceso GUI (Gráfico)

Utilizado para administración visual. Protocolos más comunes:
RDP (Windows), VNC (Multiplataforma).
