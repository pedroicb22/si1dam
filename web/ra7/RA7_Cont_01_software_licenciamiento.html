📦 Clasificación del Software

El software no es un bloque monolítico. Según la función que cumple en el sistema, se clasifica en tres grandes categorías:

Software de Sistema

Permite que el hardware funcione y proporciona la plataforma para otras aplicaciones.

  • • Sistemas Operativos (Windows, Linux)
  • • Controladores (Drivers)
  • • BIOS / UEFI

Software de Aplicación

Diseñado para ayudar al usuario a realizar una tarea específica.

  • • Ofimática (Word, Excel)
  • • Navegadores (Chrome, Firefox)
  • • Gestión (ERP, CRM)

Software de Programación

Herramientas que permiten a los desarrolladores crear otros programas.

  • • IDEs (VS Code, IntelliJ)
  • • Compiladores (GCC)
  • • Depuradores (GDB)

📜 Modelos de Licencia

La licencia es el contrato legal que define los derechos de uso, copia y modificación del software.

Software Propietario

Ej: Microsoft Office, Adobe Photoshop.

El código fuente es secreto. El usuario compra el derecho de uso, pero no la propiedad del software.

Software Libre y Open Source

Ej: Linux, LibreOffice, VLC.

El código es público. Permite estudiar, modificar y redistribuir el programa.

🎯 Selección de Software para Entornos Productivos

Elegir un software no es solo mirar el precio. Un técnico debe analizar la viabilidad basándose en criterios técnicos y económicos.

Criterios Técnicos

  • ✔ Compatibilidad: ¿Funciona con el SO y hardware actual?
  • ✔ Escalabilidad: ¿Soportará más usuarios en el futuro?
  • ✔ Soporte: ¿Existe documentación oficial y soporte técnico?

TCO (Total Cost of Ownership)

El coste real no es la licencia, sino la suma de:

Precio Licencia + Coste Instalación + Formación Usuarios + Mantenimiento Mensual + Energía/Hardware.
