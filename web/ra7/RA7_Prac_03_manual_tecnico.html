Criterio c) Documentación Ofimática

Módulo: Sistemas Informáticos • RA7

Taller de Documentación Profesional

El objetivo es crear un documento técnico que cumpla con los estándares de la industria, utilizando la co-edición en tiempo real.

Flujo de Trabajo:

  • Crear un documento en Google Docs o Word Online.
  • Implementar la estructura formal: Portada $\rightarrow$ Índice Automático $\rightarrow$ Introducción $\rightarrow$ Cuerpo Técnico $\rightarrow$ Bibliografía.
  • Usar la función de comentarios y sugerencias para revisar la redacción técnica del compañero.
  • Aplicar estilos consistentes (Título 1, Título 2, Cuerpo) para asegurar que el índice funcione.

Verificación Final

El documento final debe ser compartido mediante enlace de "Solo Lectura" y debe contener el historial de revisiones activo.
