< Práctica 02: Diseño de Ecosistema de Software

Criterio b) Análisis de Necesidades

Módulo: Sistemas Informáticos • RA7

Caso: Equipamiento para Startup Tecnológica

Una nueva startup de desarrollo de software necesita equipar a su equipo. Tienes un presupuesto limitado y debes optimizar el balance entre coste y rendimiento técnico.

El Equipo:

  • • 5 Programadores (Necesito IDEs, Docker, Git).
  • • 2 Diseñadores UI/UX (Necesito Adobe Suite o Figma).
  • • 1 Administrador de Sistemas (Sistemas de Monitorización, SSH).

Tu Tarea:

Propón el conjunto de software necesario. ¿Usarás Windows o Linux? ¿Pago o Open Source? Justifica la elección basándote en el TCO (Total Cost of Ownership) y la compatibilidad entre equipos.

Entregable Technical

Documento de propuesta técnica que incluya: 1. Lista de software por rol. 2. Tabla de costes estimados. 3. Justificación de las herramientas seleccionadas.
