✨ Práctica 05: Transferencia de Ficheros Pesados

Criterio e) Servicios de Transferencia

Módulo: Sistemas Informáticos • RA7

Gestión de Datos de Gran Volumen

Cuando los archivos superan el límite de los adjuntos de email (típicamente 25MB), debemos recurrir a servicios de transferencia especializados.

Método 1: Transferencia Efímera (WeTransfer)

Subir la imagen de disco .iso del sistema operativo y enviar el enlace la cuenta del profesor.

Método 2: Almacenamiento Persistente (Nextcloud/OneDrive)

Crear un enlace compartido de una carpeta de backup y configurar los permisos de acceso (Solo lectura).

Verificación de Integridad (Hash)

Para asegurar que el archivo no se corrompió durante la carga, el alumno debe generar un Hash MD5 o SHA-256 del archivo antes del envío y el profesor debe validarlo tras la descarga.

# Linux: sha256sum archivo.iso
# Windows (PowerShell): Get-FileHash archivo.iso
