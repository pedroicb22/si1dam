⚙️ Configuración de Red en el Host

Para que un equipo se comunique, necesita tres datos básicos: una IP, una Máscara y un Gateway (Puerta de enlace).

Asignación Estática vs DHCP

  • • Estática: Manual. Ideal para servidores y equipos de infraestructura (impresoras, routers).
  • • DHCP: Automática. El servidor DHCP asigna la IP mediante el proceso DORA (Discover, Offer, Request, Acknowledge).

Ruta de Configuración (Linux)

// Interfaces de red

/etc/network/interfaces

// Servidores DNS

/etc/resolv.conf

🛡️ Puertos y Seguridad de Transporte

Los puertos permiten que un mismo IP maneje múltiples servicios simultáneamente. Se dividen en puertos bien conocidos (< 1024) y efímeros.

ServicioPuertoProtocoloSeguridad
SSH22TCPCifrado
HTTP80TCPLlanura
HTTPS443TCPTLS/SSL
DNS53UDP/TCPBásico

Concepto de Firewalling

Un Firewall actúa como un filtro que decide qué tráfico entra o sale basado en reglas de IP de origen, Puerto y Protocolo. Por ejemplo, cerrar el puerto 23 (Telnet) y abrir el 22 (SSH) es la primera medida de hardening de red.
