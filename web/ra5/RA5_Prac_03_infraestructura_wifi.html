✨ Práctica 03: Despliegue de Infraestructura Wi-Fi

Criterio c) Redes Inalámbricas

Módulo: Sistemas Informáticos • RA5

Configuración de Punto de Acceso

El objetivo es crear una red WLAN segura y optimizada para evitar interferencias en un entorno saturado de señales.

Tareas a realizar:

  • Configurar el SSID (nombre de red) y marcarlo como oculto para reducir la visibilidad.
  • Implementar el estándar de seguridad WPA3 con una contraseña robusta.
  • Analizar los canales disponibles y seleccionar el canal con menor ruido para optimizar el rendimiento.

Validación de Señal

Cliente conecta exitosamente al SSID oculto.
Verificación de cifrado WPA3 activo.
Captura de pantalla de un analizador de espectro Wi-Fi mostrando el canal seleccionado.
