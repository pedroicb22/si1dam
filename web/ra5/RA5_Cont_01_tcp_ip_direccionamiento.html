🌐 Arquitectura de Capas TCP/IP

El modelo TCP/IP es el estándar real de internet. A diferencia del modelo OSI (7 capas), TCP/IP simplifica la comunicación en 4 capas funcionales:

TCP (Transmission Control Protocol)

  • • Orientado a conexión: Establece un apretón de manos (3-way handshake).
  • • Fiable: Garantiza que los datos lleguen completos y en orden.
  • • Control de flujo: Evita que el emisor sature al receptor.

UDP (User Datagram Protocol)

  • • Sin conexión: Envía datos sin verificar si el receptor está listo.
  • • Velocidad máxima: Menor sobrecarga (overhead) que TCP.
  • • Usos típicos: Streaming de video, juegos online, VoIP.

📍 Direccionamiento IPv4 y Subnetting

Una dirección IPv4 consiste en 32 bits divididos en 4 octetos. Para optimizar la red, se utiliza el Subnetting para dividir una red grande en segmentos más pequeños y gestionables.

🚀 El Futuro: IPv6 y Resolución DNS

IPv6 (Internet Protocol version 6)

Nace para solucionar el agotamiento de direcciones IPv4. Utiliza 128 bits representados en hexadecimal.

  • • Unicast: Comunicación uno-a-uno.
  • • Multicast: Envío a un grupo específico.
  • • Anycast: Envío al nodo más cercano.

DNS (Domain Name System)

Traduce nombres legibles (google.com) en direcciones IP numéricas.

Consulta $\rightarrow$ Servidor Raíz $\rightarrow$ TLD (.com) $\rightarrow$ Servidor Autoritativo $\rightarrow$ IP Final.
