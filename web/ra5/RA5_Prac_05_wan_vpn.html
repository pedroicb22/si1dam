✨ Práctica 05: Acceso WAN y VPN

Criterio e) Acceso a redes WAN

Módulo: Sistemas Informáticos • RA5

Simulación de Red Extendida

Configuraremos la salida de la red local hacia la red global y crearemos un túnel seguro para el teletrabajo.

Tareas a realizar:

  • Configurar el puerto WAN del router para obtener IP mediante DHCP del ISP.
  • Implementar la instalación de un servidor VPN (WireGuard o OpenVPN) en la red interna.
  • Generar las claves públicas y privadas para el cliente VPN.
  • Configurar la regla de firewall (Port Forwarding) en el router para permitir el tráfico del túnel VPN.

Verificación de Tunelización

Cliente VPN conecta desde una red externa (simulada).
Ping exitoso desde la IP del túnel VPN hacia el servidor interno de la LAN.
Verificación de cifrado del tráfico mediante captura de paquetes.
