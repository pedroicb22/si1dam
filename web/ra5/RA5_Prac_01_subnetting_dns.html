Criterio a) Configuración TCP/IP

Módulo: Sistemas Informáticos • RA5

El Reto de Subnetting

Se te ha asignado el rango 192.168.10.0/24. Debes segmentar la red para optimizar el tráfico y la seguridad.

Tareas a realizar:

  • Dividir la red en 4 subredes iguales (calcular nueva máscara y rango de cada una).
  • Configurar la IP estática, máscara y Gateway en tres equipos distribuidos en subredes distintas.
  • Configurar un servidor DNS local para que los equipos se encuentren por nombre (ej. srv-dns.local).

Criterios de Aceptación

Ping exitoso entre dos equipos de la misma subred.
Fallo de ping entre equipos de subredes distintas (sin router activo).
Resolución de nombre exitosa mediante el servidor DNS configurado.
