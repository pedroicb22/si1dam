Diagnóstico y Monitorización de Red

Módulo: Sistemas Informáticos • RA5: Interconexión de Sistemas en Red

🛠️ Kit de Supervivencia CLI

Pruebas de Conectividad

  • ping: Verifica si un host está vivo mediante ICMP.
  • traceroute (tracert): Muestra los saltos (routers) que da un paquete hasta el destino.
  • nslookup / dig: Diagnóstico de resolución de nombres DNS.

Inspección de Estado

  • ip addr: Muestra interfaces y sus IPs asignadas.
  • netstat -tunlp: Lista puertos abiertos y procesos que los usan.
  • arp -a: Muestra la tabla de correspondencia IP $\rightarrow$ MAC.

// Flujo típico de diagnóstico

1. ¿Tengo IP? $\rightarrow$ ip addr
2. ¿Llego a mi Gateway? $\rightarrow$ ping [Gateway_IP]
3. ¿Tengo DNS? $\rightarrow$ ping google.com
4. ¿Dónde se corta el camino? $\rightarrow$ traceroute 8.8.8.8

🔍 Captura y Monitorización

Cuando los comandos básicos no bastan, recurrimos al análisis de paquetes (Packet Sniffing) para observar exactamente qué viaja por el cable.

Wireshark / tcpdump

Herramientas capaces de capturar tramas y reconstruir sesiones completas de TCP.

sudo tcpdump -i eth0 port 80

SNMP (Simple Network Mgmt Protocol)

Permite monitorizar la carga de CPU de un switch, el ancho de banda de una interfaz o el estado de una fuente de alimentación de forma remota.

# network-diagnostics # ping-traceroute # wireshark-tcpdump # snmp-monitoring
