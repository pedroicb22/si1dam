1.2 El Procesador (Central Processing Unit)

El componente encargado de ejecutar las instrucciones de los programas mediante operaciones aritméticas y lógicas.

La CPU es el cerebro del sistema. Su función es leer instrucciones desde la memoria principal, interpretarlas y ejecutar las acciones correspondientes. Para lograr esto, se basa en la Arquitectura de Von Neumann, donde los datos y las instrucciones residen en la misma memoria.

1 Arquitectura Interna de la CPU

ALU

Unidad Aritmético-Lógica

Realiza todas las operaciones matemáticas (suma, resta) y lógicas (AND, OR, NOT, Comparaciones) necesarias para procesar los datos.

CU

Unidad de Control

Actúa como la directora de orquesta. Decodifica las instrucciones y envía señales de control a la ALU, la memoria y los periféricos.

REG

Registros Internos

Memorias ultrarrápidas de bajísima capacidad. Ejemplos: PC (Contador de Programa), IR (Registro de Instrucción).

2 Sets de Instrucciones: RISC vs CISC

CISC (Complex Instruction Set Computing)

Enfoque en reducir el número de instrucciones por programa, creando instrucciones complejas que pueden realizar varias tareas en un solo ciclo.

  • • Instrucciones de longitud variable.
  • • Mayor uso de memoria para el hardware, menor para el código.
  • • Ejemplo: Arquitectura x86 (Intel, AMD).

RISC (Reduced Instruction Set Computing)

Enfoque en instrucciones simples y optimizadas que se ejecutan en un solo ciclo de reloj, delegando la complejidad al compilador.

  • • Instrucciones de longitud fija.
  • • Muy eficiente en consumo energético y calor.
  • • Ejemplo: Arquitectura ARM (Apple M1/M2, Qualcomm).

3 Gestión de Interrupciones

Una interrupción es una señal enviada a la CPU que indica que un evento requiere atención inmediata. La CPU pausa su tarea actual, guarda el estado y ejecuta una rutina especial llamada ISR (Interrupt Service Routine).

Interrupciones de Hardware

Generadas por periféricos. Ejemplo: Pulsar una tecla del teclado o la llegada de un paquete de red.

Interrupciones de Software (Traps)

Generadas por el propio programa. Ejemplo: División por cero o solicitud de un servicio al SO (System Call).

4 Rendimiento y Jerarquía de Memoria

El rendimiento de una CPU no depende solo de la frecuencia (GHz), sino de la eficiencia en la gestión de datos:

  • Núcleos y Hilos: Un núcleo es una CPU física. El Hyper-Threading permite que un núcleo gestione dos hilos de ejecución simultáneos.
  • Memoria Caché: Memoria SRAM integrada en la CPU para evitar acceder a la lenta RAM. Se divide en L1 (ultrarrápida/pequeña), L2 y L3 (más lenta/grande).
