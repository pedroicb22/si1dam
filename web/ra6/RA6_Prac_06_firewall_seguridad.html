🛡️ Práctica 06: Implementación de Firewall y Seguridad

Criterio f) Utilidades de seguridad básica

Módulo: Sistemas Informáticos • RA6

Defensa Perimetral y Anti-BruteForce

Un servidor expuesto a la red es blanco constante de ataques. Implementaremos un firewall restrictivo y una herramienta de bloqueo automático.

Tarea 1: Firewall Restrictivo

Configurar el firewall para bloquear todo el tráfico entrante, permitiendo únicamente el tráfico la red la cual sea necesaria para la administración (estricto SSH puerto 22).

sudo ufw default deny incoming
sudo ufw allow 22/tcp

Tarea 2: Fail2Ban

Instalar Fail2Ban. Configurar la regla para que cualquier IP que falle 3 intentos de login por SSH sea baneada automáticamente durante 1 hora.

Prueba de Intrusión

Intentar acceder por un puerto no permitido $\rightarrow$ El paquete debe ser descartado.
Realizar 4 intentos de login fallidos $\rightarrow$ Comprobar que la IP queda bloqueada en fail2ban-client status sshd.
