✨ Práctica 01: Servidor de Archivos con Samba

Criterio a) Acceso a recursos de red

Módulo: Sistemas Informáticos • RA6

Escenario de Interoperabilidad

Samba es la herramienta clave para que Linux y Windows "hablen el mismo idioma" (SMB). Debes montar un servidor de archivos híbrido.

Tareas a realizar:

  • Instalar y configurar la suite samba en el servidor Linux.
  • Crear un recurso "Publico": Permitir acceso a usuarios Guest (sin contraseña) solo para lectura.
  • Crear un recurso "Privado": Configurar autenticación obligatoria y permisos de lectura/escritura solo para usuarios registrados.

Prueba de Verificación

Desde Windows, escribir \\ip_servidor en el explorador y ver ambas carpetas.
Intentar entrar en "Privado" sin usuario $\rightarrow$ Debe solicitar credenciales.
Crear un documento en "Privado" y verificar que se guarda correctamente.
