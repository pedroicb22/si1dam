🏢 Dominios y Administración Centralizada

En redes empresariales, gestionar cada PC individualmente es inviable. Un Dominio permite centralizar la autenticación y la configuración en un solo servidor (Controlador de Dominio).

Active Directory (AD) / LDAP

Es la base de datos jerárquica que contiene todos los objetos de la red: usuarios, equipos, impresoras y grupos.

  • • OU (Unidades Organizativas): Contenedores para organizar objetos y aplicar políticas específicas.
  • • Bosques y Árboles: Estructuras para conectar múltiples dominios.

🛠️ GPO: Configuración Masiva

Las Objetos de Política de Grupo (GPO) permiten definir configuraciones que se aplican automáticamente a miles de usuarios o equipos sin tocarlos físicamente.
