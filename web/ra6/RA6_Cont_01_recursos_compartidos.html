📁 Recursos Locales vs. Recursos de Red

Compartir recursos permite la colaboración y la centralización de la gestión. Dependiendo del SO, utilizamos diferentes protocolos de transporte de archivos.

SMB / CIFS (Windows & Samba)

Es el protocolo estándar de Windows. Permite compartir archivos, impresoras y puertos serie.

// Acceso mediante ruta UNC

\\\|SERVIDOR_ARCHIVOS\\\|Carpeta_Publica

NFS (Network File System)

Protocolo nativo de Unix/Linux. Se centra en la eficiencia y el montaje directo en el árbol de directorios local.

// Montaje de recurso remoto

sudo mount -t nfs 192.168.1.10:/var/exports /mnt/red

🔐 Permisos de Compartición vs NTFS

En entornos Windows, para acceder a un archivo en red, el sistema evalúa dos capas de permisos. El resultado final es siempre el permiso más restrictivo.

graph LR A[Intento de Acceso] --> B{Permiso de Red/Share} B -- Permite --> C{Permiso NTFS/Disco} B -- Deniega --> D[Acceso Denegado] C -- Permite --> E[ACCESO CONCEDIDO] C -- Deniega --> D style E fill:#10b981,color:#fff style D fill:#ef4444,color:#fff

Permisos de Compartición

Controlan la "puerta" de entrada al recurso vía red. Ej: Lectura, Cambio, Control Total.

Permisos NTFS

Controlan qué puede hacer el usuario una vez dentro (estén en la red o localmente). Son mucho más granulares.
