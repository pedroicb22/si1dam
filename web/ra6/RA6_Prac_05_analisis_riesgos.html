📦 Práctica 05: Análisis de Riesgos de Recursos

Criterio e) Evaluación de protección de recursos

Módulo: Sistemas Informáticos • RA6

Auditoría de Permisos

Un error común en la administración de servidores es asignar permisos excesivos (ej. 777 en Linux o "Todos: Control Total" en Windows) para solucionar problemas de acceso rápido, creando agujeros de seguridad graves.

Tareas a realizar:

  • Explorar el sistema de archivos del servidor y localizar carpetas con permisos rwxrwxrwx.
  • Identificar la vulnerabilidad: ¿Puede un usuario sin privilegios borrar archivos del sistema o leer datos de otros usuarios?
  • Proponer una matriz de permisos basada en el Principio de Mínimo Privilegio (dar solo el acceso estrictamente necesario).

Entregable

El alumno deberá entregar un informe breve con: 1. Ruta del recurso vulnerable. 2. Riesgo asociado. 3. Comando de corrección propuesto (ej. chmod 750).
