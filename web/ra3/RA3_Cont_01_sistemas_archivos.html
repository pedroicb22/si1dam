1.1. El Sistema de Archivos (File System)

¿Qué es exactamente?

Un sistema de archivos es la estructura lógica que utiliza un sistema operativo para organizar, almacenar, recuperar y gestionar los datos en un dispositivo de almacenamiento. Sin él, el disco sería una masa amorfa de bits sin saber dónde empieza un archivo y dónde termina otro.

Funciones principales:

  • Gestión del espacio libre y ocupado.
  • Asignación de metadatos (nombre, tamaño, fecha de creación).
  • Control de permisos y seguridad de acceso.
  • Mantenimiento de la integridad de los datos.

Comparativa Técnica de File Systems

Sistema Uso Principal Características Clave Limitación Crítica

NTFS Windows Moderno Journaling, seguridad avanzada, cuotas. Escritura limitada en macOS/Linux
ext4 Linux Estándar Extremadamente estable, soporta archivos gigantes. Incompatible nativo con Windows
exFAT Discos Externos / SDXC Optimizado para flash, sin límites de 4GB. Menos robusto que NTFS/ext4

El Concepto de Journaling

El Journaling es una técnica que mantiene un registro (log) de los cambios que se van a realizar antes de escribirlos definitivamente en el sistema de archivos. Si ocurriera un apagón repentino, el sistema consulta el log para completar la operación o revertirla, evitando la corrupción total del sistema de archivos.

1.2. Estructura de Directorios

Linux: FHS (Filesystem Hierarchy Standard)

Linux utiliza una estructura de árbol única donde todo parte de la raíz /.

/bin Binarios esenciales del sistema (comandos básicos).
/etc Archivos de configuración global del sistema y servicios.
/home Directorios personales de los usuarios comunes.
/var Datos variables (logs, bases de datos, colas de correo).
/dev Archivos de dispositivo (interfaz al hardware).

Windows: Estructura de Unidades

A diferencia de Linux, Windows utiliza un sistema de particiones identificadas por letras de unidad (C:, D:, etc.).

C:\Windows Núcleo del sistema operativo y archivos críticos.
System32 Librerías DLL y ejecutables fundamentales del sistema.
Users\ Perfiles de usuario, documentos y configuraciones personales.
Program Files Instalaciones de software de terceros.

Análisis Comparativo para el Alumno

  • Abstracción: Mientras que Windows separa el hardware en "Unidades", Linux lo integra todo en un único árbol jerárquico.
  • Estabilidad: El Journaling es la razón por la cual NTFS y ext4 son preferibles a FAT32 en discos de sistema.
  • FHS: Es vital que un administrador de sistemas conozca el FHS para saber dónde buscar logs (/var/log) o configuraciones (/etc).
