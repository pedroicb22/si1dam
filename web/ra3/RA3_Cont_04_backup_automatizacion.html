4.1. Estrategias de Copia de Seguridad

La Regla de Oro: 3-2-1

En la administración profesional de datos, no basta con "copiar los archivos". Para garantizar que una empresa no pierda su información ante un desastre (incendio, ransomware, fallo masivo de hardware), se aplica el estándar 3-2-1:

3 Mantener al menos 3 copias de los datos (Original + 2 backups).
2 Almacenar los datos en 2 soportes diferentes (ej. Disco local y NAS/Nube).
1 Guardar al menos 1 copia fuera de sitio (Off-site), lejos de la ubicación física principal.

Soportes híbridos: Local + Nube

Copia Completa

Copia absolutamente todo el sistema.

  • (+) Recuperación más rápida.
  • (-) Tarda mucho tiempo en crearse.
  • (-) Consume máximo espacio.

Copia Incremental

Solo copia lo cambiado desde el último backup (de cualquier tipo).

  • (+) Muy rápida de crear.
  • (+) Mínimo espacio.
  • (-) Recuperación lenta (Requiere cadena completa).

Copia Diferencial

Copia lo cambiado desde la última copia completa.

  • (+) Recuperación intermedia.
  • (+) Más rápida que la completa.
  • (-) Crece en tamaño hasta la próxima completa.

Herramientas Profesionales

rsync (Linux)

la herramienta estándar para backups eficientes. Solo transfiere las partes del archivo que han cambiado.

tar (Linux)

Archivo y compresión de datos en un solo fichero (.tar, .tar.gz).

Windows Backup / File History

Herramientas nativas para copias de seguridad automáticas de carpetas de usuario.

Veeam / Bacula

Software de nivel empresarial para gestión de backups masivos y la nube.

4.2. Tareas Automáticas y Planificación

Cron (Linux)

Cron es el demonio de planificación de tareas en Unix. Permite ejecutar scripts en intervalos precisos basados en una "crontab".

Sintaxis de la Crontab

Minutos
Horas
Día Mes
Mes
Día Sem.
0 2 * * * /home/user/scripts/backup.sh

Ejecuta el script de backup todos los días a las 02:00 AM.

Tareas Programadas (Windows)

Interface gráfica y CLI (schtasks) para ejecutar scripts .bat o .ps1 basándose en eventos del sistema (inicio, hora, inactividad).

Interfaz del Programador de Tareas de Windows

Ventaja de Windows: Permite disparar tareas basadas en eventos específicos del registro (Event Viewer), lo que es vital para backups preventivos ante errores de disco.

Automatización mediante Scripts Básicos

Un administrador no ejecuta los comandos uno a uno; crea scripts que encapsulan la lógica de backup y mantenimiento.

Linux (.sh)
#!/bin/bash
tar -czf /backup/data_$(date +%F).tar.gz /home/user/docs
echo "Backup Completado"
Windows (.bat / .ps1)
robocopy "C:\Datos" "D:\Backup" /MIR /Z
echo Backup la realizado con exito.

Resumen de Supervivencia de Datos

  • Un backup que no se ha probado la restauración no es un backup, es una esperanza.
  • La regla 3-2-1 es la única garantía real contra desastres físicos y lógicos.
  • La automatización elimina el error humano y asegura que la política de backups se cumpla estrictamente.
