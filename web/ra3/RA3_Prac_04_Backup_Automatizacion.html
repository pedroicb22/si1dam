RA3: Prácticas Módulo: Sistemas Informáticos

✨ Práctica 4: Backup Automatizado y Planificación

Implementación de la resiliencia de datos mediante el desarrollo de scripts de copia incremental y su programación en el sistema.

CRITERIO F

Actividad 1: Implementación de Plan de Backup Automatizado

Objetivo:

Desarrollar la capacidad de crear copias de seguridad eficientes utilizando herramientas de sincronización y compresión, asegurando la integridad de los datos.

Flujo de datos: Origen $\rightarrow$ Filtrado $\rightarrow$ Compresión $\rightarrow$ Destino Seguro

📍 Desarrollo del Script backup.sh

El alumno debe programar un script en Bash que realice las siguientes operaciones técnicas:

1
Sincronización Incremental: Utilizar rsync para copiar la carpeta /home/alumno/documentos hacia un repositorio externo, copiando solo los archivos modificados.
2
Compresión y Archivado: Empaquetar el resultado final utilizando tar con compresión gzip para optimizar el espacio.
3
Verificación de Destino: Implementar un condicional if [ -d /ruta/destino ]. Si la unidad de backup no está montada, el script debe generar una alerta en la consola y en el log del sistema.

Entregable

Código fuente del script backup.sh y captura de la ejecución exitosa.

Verificación

Borrar un archivo del origen, ejecutar el script y comprobar que la restauración desde el backup es total.

CRITERIO G

Actividad 2: Implementación de Tareas Programadas

Objetivo:

Eliminar la intervención humana en el proceso de backup mediante el uso de planificadores del sistema operativo.

Planificación en Linux (Cron)

El alumno debe configurar la tabla de tiempos del sistema para que el script la tarea se automatice.

0 3 * * 0 /home/alumno/scripts/backup.sh

Configuración: Ejecutar cada Domingo (0) a las 03:00 AM.

Planificación en Windows

Utilizando la interfaz del "Programador de Tareas", se debe crear un disparador automático.

Tarea: Limpieza de carpeta Temp.

Disparador: Semanal $\rightarrow$ Viernes $\rightarrow$ Al apagar el equipo.

Acción: Ejecutar script clean_temp.bat.

Entregable

Captura de la crontab -l de Linux y captura del panel de tareas de Windows.

Verificación

Comprobación de la sintaxis del cron y validación de los disparadores en el Programador de Windows.

El "Arte" del Backup

"Un administrador de sistemas no es evaluado por la calidad de sus backups, sino por la rapidez y el éxito de sus restauraciones. Automatizar la copia es la mitad del trabajo; la otra mitad es el plan de recuperación ante desastres."
