✨ Práctica 5: Gestión de Aplicaciones y Documentación

Implementación de software mediante diversas metodologías de despliegue y redacción de manuales técnicos de instalación.

CRITERIO H

Actividad 1: Gestión de Paquetes y Repositorios

Objetivo:

Dominar las diferentes rutas de instalación de software, desde la abstracción del gestor gráfico hasta el control absoluto de la terminal.

📍 Laboratorio de Instalación Multivía:

El alumno debe instalar un set de herramientas específicas en sus máquinas virtuales utilizando tres métodos distintos:

Método 1: Gráfico

Instalar la suite de oficina (LibreOffice/MS Office) mediante el Software Center o el instalador oficial GUI.

Método 2: Terminal

Instalar herramientas de red (Vim, Curl, Net-tools) usando apt-get, yum o dnf según la distro.

Método 3: Independiente

Descargar e instalar un paquete externo (.deb, .msi o .exe) manualmente desde la web del proveedor.

Reto técnico: Utilizar la terminal para verificar la versión instalada de cada paquete y localizar el directorio donde se han almacenado los binarios del programa.

Entregable

Lista de software instalado con captura de pantalla de la terminal mostrando la versión de los paquetes.

Verificación

Correcta ejecución de los tres métodos de instalación y comprobación de rutas de binarios.

CRITERIO I

Actividad 2: Manual de Instalación Paso a Paso

Objetivo:

Desarrollar la capacidad de redactar documentación técnica profesional, permitiendo que un tercero pueda replicar el entorno instalado sin ayuda externa.

📍 El Proyecto Final de RA2: La Guía Técnica

Basándose en todo el trabajo realizado desde la Práctica 1 hasta la 4, el alumno elaborará un Manual de Instalación que incluya:

  • Índice y Glosario: Términos técnicos utilizados (Kernel, ISO, GPT, etc.).
  • Flujo de Instalación: Capturas de pantalla detalladas de cada paso crítico (Particionado, Configuración de Usuarios, Instalación de Drivers).
  • Sección de "Troubleshooting": Descripción de al menos dos incidencias encontradas durante el proceso y cómo se resolvieron (ej. error de arranque, falta de drivers de red).
  • Verificación Final: Pruebas realizadas para demostrar que el sistema es estable y funcional.

Entregable

Documento PDF profesional siguiendo normas de redacción técnica (estilo manual de fabricante).

Verificación

Calidad de las capturas, claridad de las instrucciones y rigor en la sección de solución de problemas.
