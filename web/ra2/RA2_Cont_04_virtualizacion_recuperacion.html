4.1. Tecnologías de Virtualización

¿Qué es la Virtualización?

Es la técnica de crear una representación basada en software (virtual) de un recurso físico, como servidores, almacenamiento, redes y aplicaciones. Permite ejecutar múltiples sistemas operativos independientes sobre un único hardware físico mediante una capa de abstracción llamada Hipervisor.

Beneficios Clave

  • ✓ Aislamiento: Fallos en una VM no afectan a otras.
  • ✓ Eficiencia: Optimización del uso del hardware.
  • ✓ Flexibilidad: Despliegue rápido de entornos de prueba.
  • ✓ Portabilidad: Las VM son archivos transportables.

Clasificación de Hipervisores (VMM)

Tipo 1: Bare-Metal (Nativo)

Se instala directamente sobre el hardware físico. No requiere un SO anfitrión, actuando él mismo como la capa de control.

Ejemplos: VMware ESXi, Microsoft Hyper-V (Server), Proxmox VE, Citrix XenServer.

Tipo 2: Hosted (Alojado)

Se ejecuta como una aplicación sobre un sistema operativo ya instalado (Windows, Linux, macOS).

Ejemplos: Oracle VirtualBox, VMware Workstation, Parallels Desktop.

Contenedores vs. Máquinas Virtuales

Característica Máquina Virtual (VM) Contenedor (Docker)
Aislamiento Completo (Hardware virtualizado) A nivel de proceso (Kernel compartido)
Peso/Tamaño Gigas (Incluye SO completo) Megas (Solo apps y dependencias)
Arranque Minutos (Boot completo del SO) Milisegundos (Sube el proceso)
Uso típico Ejecutar SOs diferentes Microservicios, despliegue ágil

4.2. Actualización y Recuperación

Puntos de Restauración

Capturas del estado del registro y archivos críticos del sistema. Permiten volver atrás tras un cambio fallido sin borrar datos personales.

Imágenes de Sistema

Copia exacta (clon) de todo el disco duro. Incluye particiones de arranque, SO y configuraciones. Es la recuperación definitiva.

Modo Seguro / Recovery

Entorno de arranque mínimo con drivers genéricos. Esencial para eliminar malware, reparar el MBR o desinstalar drivers corruptos.

Actualizaciones Críticas: Son aquellas que corrigen vulnerabilidades de seguridad graves (Zero-day) o fallos catastróficos del sistema. Deben implementarse con prioridad máxima.

Despliegue de Versiones: Proceso de migración a una nueva versión mayor del SO (ej. Windows 10 → 11), requiriendo auditoría de compatibilidad de hardware y software.

Resumen Técnico para el Alumno

  • Un hipervisor Tipo 1 es más eficiente que uno Tipo 2 porque elimina el SO anfitrión.
  • Los contenedores no virtualizan el hardware, sino el entorno de ejecución del proceso.
  • La recuperación por imágenes es la única garantía total contra fallos catastróficos del hardware de almacenamiento.
  • El patch management es fundamental en entornos empresariales para evitar el caos de versiones.
