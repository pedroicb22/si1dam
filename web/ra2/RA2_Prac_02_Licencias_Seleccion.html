✨ Práctica 2: Licencias y Selección de SO

Análisis de costes, legalidad de software y consultoría técnica para despliegue de entornos operativos.

CRITERIO C

Actividad 1: Consultoría de Selección de SO

Objetivo:

Saber elegir el sistema operativo adecuado basándose en el binomio Compatibilidad de Software $\leftrightarrow$ Coste de Licencia.

Caso de Estudio: Agencia "PixelArt Studio"

La agencia necesita renovar su infraestructura. Han solicitado la implementación de:

  • 3 Estaciones de Trabajo High-End: Para edición de video 4K, renderizado 3D y diseño gráfico profesional.
  • 1 Servidor de Archivos Central: Para almacenamiento masivo, copias de seguridad automáticas y acceso compartido para todos los diseñadores.

📍 Tarea del Alumno:

Diseña una propuesta técnica que incluya una tabla con las siguientes columnas:

Puesto SO Propuesto Tipo de Licencia Justificación Técnica
Ejemplo: Servidor Ubuntu Server GNU GPL (Libre) Estabilidad, seguridad, coste 0 y gran soporte de redes.

Análisis de Costes: Compara el coste aproximado de licenciar los 3 puestos con Windows 11 Pro frente a una alternativa Libre. ¿Es viable la alternativa libre para el flujo de trabajo de Adobe Creative Cloud?

Entregable

Documento de Propuesta Técnica (PDF) con cuadro comparativo y análisis de licencias.

Verificación

Coherencia entre el software requerido y el SO elegido. Justificación correcta del tipo de licencia.

Guía Rápida de Licencias

Propietaria (EULA): Pagas por el derecho de uso, no eres dueño del software. Restricciones de instalación y copia.
GNU GPL (Copyleft): Libre para usar, estudiar, modificar y distribuir. Obliga a que las mejoras sigan siendo libres.
