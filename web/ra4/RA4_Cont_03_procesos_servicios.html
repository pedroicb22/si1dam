⚙️ Ciclo de Vida del Proceso

Un proceso es un programa en ejecución. A diferencia de un programa (estático), el proceso es una entidad dinámica que requiere recursos (RAM, CPU).

stateDiagram-v2 [*] --> Nuevo Nuevo --> Ejecutando: Asignación CPU Ejecutando --> Espera: I/O o Evento Espera --> Ejecutando: Evento Completado Ejecutando --> Listo: Interrupción/Quantum Listo --> Ejecutando: Planificador Ejecutando --> Terminado: Salida/Error

Estados Críticos

  • Zombie: Proceso que ha terminado pero cuyo padre no ha leído el código de salida.
  • Dormido (Interruptible): Esperando un evento externo.
  • Planificación (Nice): Valor que indica la prioridad. En Linux, un valor de +19 es la prioridad más baja.

🌐 Servicios y Daemons

Los servicios son procesos que se ejecutan en segundo plano (background) y suelen iniciar con el sistema para proporcionar funcionalidades básicas.

Systemd (Linux)

sudo systemctl start apache2 # Inicia el servicio sudo systemctl enable apache2 # Auto-arranque systemctl status ssh # Verifica estado

Services.msc (Windows)

Gestión mediante consola MMC o comandos sc config y net start/stop.
