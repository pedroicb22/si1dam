🔐 Modelos de Permisos Básicos

Modelo Unix/Linux (Posix)

Se basa en la tríada Usuario, Grupo, Otros. Cada uno de estos puede tener tres tipos de permisos básicos:

  • ✔ Lectura (r): Acceso al contenido del archivo.
  • ✔ Escritura (w): Modificación del archivo o directorio.
  • ✔ Ejecución (x): Ejecutar un binario o entrar en un directorio.

Modelo Windows (NTFS)

Más complejo y granular que el de Linux, basado en el concepto de SIDs (Security Identifiers) y descriptores de seguridad.

  • ✔ Control Total: Permiso para hacer cualquier cambio y cambiar permisos.
  • ✔ Modificar: Leer, escribir y eliminar.
  • ✔ Lectura y Ejecución: Solo ver y ejecutar scripts/programas.

// Ejemplo de cambio de permisos en Linux

# Cambiar propietario a 'admin' y grupo a 'webmasters'
sudo chown admin:webmasters /var/www/html/index.html

# Establecer permisos: Owner(rwx), Group(rx), Others(r-x)
chmod 754 /var/www/html/index.html

📊 Flujo de Verificación de Acceso

graph TD A[Solicitud de Acceso] --> B{¿Es el Usuario Propietario?} B -- Sí --> C[Aplicar Permisos de Usuario] B -- No --> D{¿Pertenece al Grupo?} D -- Sí --> E[Aplicar Permisos de Grupo] D -- No --> F[Aplicar Permisos de "Otros"] C --> G[¿Acceso Concedido?] E --> G F --> G G -- Sí --> H[Ejecutar Acción] G -- No --> I[Error: Permiso Denegado]

📜 Listas de Control de Acceso (ACL)

Cuando el modelo básico u-g-o no es suficiente (por ejemplo, si necesitamos dar permisos a un usuario específico que no es el dueño ni pertenece al grupo principal), utilizamos las ACL (Access Control Lists).

ACL en Linux (POSIX)

Permite definir permisos para múltiples usuarios y grupos específicos.

// Dar lectura y escritura al usuario 'auditor' en la carpeta /datos

setfacl -m u:auditor:rw- /datos

// Ver la ACL actual del archivo

getfacl /datos

Herencia en Windows

Los objetos heredan permisos de sus carpetas padre a menos que se desactive la herencia explícitamente.

  • • Permisos Heredados: Propagados automáticamente hacia abajo.
  • • Permisos Explícitos: Configurados directamente en el archivo/carpeta.
  • • Precedencia: El permiso explícito suele anular al heredado.
