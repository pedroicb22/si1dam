1.1 Gestión de Identidades

La identidad de un sistema operativo es la base de su seguridad. No todos los procesos ni todas las personas interactúan con el sistema de la misma manera.

Cuentas de Usuario

  • Locales: Definidas en la máquina física.
  • Dominio: Centralizadas (Active Directory/LDAP).
  • Sistema: Para servicios internos (ej. mysql, www-data).
  • Administrador: El usuario root (Linux) o Administrator (Windows).

Gestión de Grupos

Los grupos permiten asignar permisos a múltiples usuarios simultáneamente.

Ej: Grupo 'DevOps' → Acceso SSH + Permisos Write en /var/www
