Criterio f) Monitorización del sistema

Módulo: Sistemas Informáticos • RA4

Análisis Forense de Eventos

El sistema debe ser capaz de registrar errores. Vamos a provocar un fallo de seguridad y rastrearlo.

Fase 1: Provocación

Intenta acceder a la carpeta /root como usuario estándar. Recibirás un "Permission Denied".

cd /root

Fase 2: Rastreo

Busca la entrada de error en el log de autenticación del sistema.

grep "denied" /var/log/auth.log

Métricas de Rendimiento

Ejecuta un proceso pesado (ej. stress o una compilación larga) y monitoriza el sistema durante 5 minutos usando vmstat o sar.

Analiza los siguientes puntos:

  • % de uso de CPU (User vs System).
  • Tasa de Swap (intercambio de memoria).
  • Carga media (Load Average).
