📜 Registros del Sistema (Logs)

El análisis de logs es la herramienta principal para el troubleshooting y la auditoría de seguridad.

Entornos Linux

  • /var/log/syslog: Log general del sistema.
  • /var/log/auth.log: Intentos de acceso y SSH.
  • dmesg: Mensajes del Kernel y hardware.
tail -f /var/log/auth.log # Monitorizar en tiempo real

Entornos Windows

Uso del Visor de Eventos (Event Viewer) dividido en categorías:

  • Aplicación: Errores de software.
  • Seguridad: Auditorías de login.
  • Sistema: Fallos de drivers o hardware.

🚀 Optimización y Tuning

CPU & RAM

Monitorizar con top o htop. Identificar procesos "zombies" o fugas de memoria.

Disk I/O

Análisis de cuellos de botella con iostat. Optimización de particiones y journaling.

Boot Time

Uso de systemd-analyze blame para eliminar servicios innecesarios al arranque.
