📝 Ofimática Moderna para Técnicos

La ofimática no es solo escribir texto; es crear documentos estructurados que sirvan como manuales técnicos profesionales.

Procesadores de Texto

  • • Estilos: Evitar el formato manual; usar H1, H2, etc.
  • • Índice Automático: Generado a partir de los estilos.
  • • Referencias: Citas bibliográficas y notas al pie.

Hojas de Cálculo

  • • Tablas Dinámicas: Resumen de grandes volúmenes de datos.
  • • Fórmulas lógicas: Uso de SI, BUSCARV, SUMAR.SI.
  • • Gráficos: Visualización de rendimiento y consumo.

Presentaciones

  • • Sintesis: Menos texto, más esquemas.
  • • Interactividad: Hipervínculos y transiciones.
  • • Narrativa: Enfoque en el problema y la solución.

🤝 Colaboración en la Nube y Control de Versiones

El trabajo técnico moderno es distribuido. Ya no enviamos "Manual_Final_v2_SÍ_ESTE_SI.doc", sino que trabajamos sobre una única fuente de verdad.

Herramientas Cloud (SaaS)

Google Workspace y MS 365 permiten la co-edición en tiempo real, eliminando la duplicidad de archivos y facilitando la revisión mediante comentarios y sugerencias.

Control de Versiones (Git)

Para la documentación técnica avanzada, se utiliza Git. Permite rastrear cada cambio, volver a versiones anteriores y trabajar en ramas (branches) independientes.

git add . # Preparar cambios git commit -m "Añadido RA7" # Guardar versión git push origin main # Subir a GitHub/GitLab
